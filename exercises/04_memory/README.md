# Exercise 04: 簡易長期記憶

## 目標

- 会話履歴をベクトル化して保存し、関連する過去の会話を検索・参照する
- FAISS を使ったローカルベクトルストアを体験する
- 長い会話でもコンテキスト長を超えないよう要約する仕組みを作る

## Exercise 03 との違い

03 まではセッション内の会話履歴のみでしたが、
ここでは **過去の会話をベクトル検索で呼び出す長期記憶** を追加します。

## 実行

```bash
uv run python exercises/04_memory/memory_chat.py
```

## ポイント

- `tiktoken` でトークン数を計測し、一定量を超えたら要約を生成
- `FAISS` で会話のやり取りをベクトル化・保存
- 新しい質問に関連する過去の会話を検索し、コンテキストに注入
- ベクトル化には LM Studio の embeddings エンドポイントを使用

## やってみよう

1. 何回か会話して、途中で「さっき話した○○って何だっけ？」と聞いてみる
2. `memory_store/` ディレクトリに FAISS インデックスが保存されることを確認
3. 再起動後も過去の会話を参照できることを確認
